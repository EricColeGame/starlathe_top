## 为什么 Starlathe 角色比裸属性更重要

新玩家倾向于追逐伤害数字最大的角色。老玩家则相反。他们会寻找技能组能解决问题的角色——能打破僵局、补上缺口，或把微小优势转化为胜利的人。

这是因为在这类游戏中，大多数战斗的胜负都取决于前几回合的站位和资源交换，而不是漫长的拉锯战。一个输出不高但拥有可靠控制工具的角色，往往比一个一旦被集火就倒下的高伤害单位贡献更大。

无论当前版本环境如何，有几条原则始终成立：

- **覆盖胜过峰值强度。** 五名各有所长却毫无重叠的专精角色组成的队伍，通常会输给四名泛用角色加一名灵活位。
- **技能组比数值更经久。** 伤害数值会被调整；功能效果往往能保值。
- **投入会复利。** 把资源投到你到处都会用的角色身上，回报远高于分散到一整个深板凳。
- **定位清晰能防止慌乱。** 当每个人都知道自己的职责时，你在压力下能更快做决定。

## 大多数 Starlathe 角色背后的核心定位原型

名单中几乎每个角色都可归入手头几种职责之一。学习这些定位原型后，你解锁新角色时就能更容易读懂他的技能组。

| 角色定位原型 | 主要职责 | 发挥场合 | 需要注意 |
| --- | --- | --- | --- |
| 先锋 / 斗士 | 承受压力、占据空间、发起战斗 | 漫长消耗战 | 被远程阵容风筝 |
| 爆发伤害 | 快速秒掉单个优先目标 | 短战斗、Boss 阶段 | 过早耗尽资源 |
| 持续伤害 | 慢慢削减、惩罚慢速队伍 | 消耗战、多波次关卡 | 被忽视到为时已晚 |
| 辅助 / 治疗 | 维持队伍生存、移除减益 | 任何战斗持续超过几回合的场合 | 成为第一个被集火的目标 |
| 控制 / 干扰 | 减速、眩晕、位移、驱散增益 | 扭转劣势战斗 | 自身伤害低 |
| 功能 / 灵活位 | 填补队伍缺少的任何位置 | 针对特定克制关系进行选人 | 什么都“还行”，却什么都不精 |

一个有用的习惯：每次失败后，问问你的队伍缺少这六种职责中的哪一种。在社区报告中，“我们没有控制位”和“我们对治疗毫无办法”出现的频率，远高于对伤害输出的抱怨。

### 混血角色并非自动更强

双定位角色很诱人，因为它们看起来高效。实际使用中，一个兼具 70% 输出手和 70% 辅助能力的混血角色，通常不如两个专职单位——除非这个混血角色的独特效果正是你带上他的全部理由。把混血角色当作附带额外效果的专精角色，而不是跳过某个定位的捷径。

## 在投入资源前如何评估一个 Starlathe 角色

在把资源倾注到新角色之前，用同一份简短清单过一遍。它只花两分钟，却能省下数小时的后悔。

| 属性 | 通常影响什么 | 为什么重要 | 优先级 |
| --- | --- | --- | --- |
| 基础属性线 | 生存能力和输出下限 | 决定这个单位有多好上手 | 前期高，后期较低 |
| 技能组机制 | 角色实际*做什么* | 使用他们的根本理由 | 最高 |
| 成长曲线 | 投入资源后能获得多少提升 | 告诉你他们是否是长期选择 | 高 |
| 能量 / 资源消耗 | 他们能多频繁行动 | 便宜、可重复的效果能赢下长时间战斗 | 中–高 |
| 队伍依赖 | 他们需要谁在身边 | 优秀单位放错队伍就是糟糕选择 | 高 |
| 灵活性 | 能融入多少种阵容 | 在多个补丁中保护你的投入 | 中 |

然后应用这份实用清单：

1. **它不需要铺垫就能行动吗？** 需要另外两个单位才能运作的角色是脆弱的选择。
2. **它有独特效果吗？** 如果某个定位已被覆盖，你需要一个重复配置的理由。
3. **低投入时它有用吗？** 有些角色需要大量装备才能有所贡献；事先要清楚这一点。
4. **它被集火时能活下来吗？** 任何在一个轮次内就会阵亡的东西，在高难内容里都是负担。
5. **技能组描述清晰吗？** 如果你不能用一句话说明这个角色做什么，你就会用错他。

玩家经验一致表明，第四点是最常被低估的一点。耐久并不光鲜，但一个留在场上的单位会持续做出贡献，而一个早早阵亡的玻璃大炮则毫无贡献。

## 队伍搭配协同与养成优先级

个体质量不如各部件之间的互动重要。用这张表诊断你当前队伍缺少什么，然后围绕缺口选人，而不是围绕最喜欢的角色选人。

| 队伍需求 | 搭配对象 | 为什么有效 |
| --- | --- | --- |
| 高爆发伤害 | 控制或减益角色 | 被控住的目标无法闪避或反击 |
| 慢速消耗阵容 | 带净化的辅助 | 移除本来会不断叠加的削减伤害 |
| 脆弱后排 | 吸引火力的先锋 | 为输出手争取第一个轮次 |
| 依赖增益的敌人 | 带驱散效果的干扰者 | 直接移除敌人的制胜条件 |
| 资源紧缺的队伍 | 低消耗功能单位 | 让行动持续运转，而不抽干资源池 |

### 各游戏阶段的养成优先级

| 阶段 | 优先做什么 | 避免什么 |
| --- | --- | --- |
| 前期 | 一个可靠输出、一个辅助、一个灵活位 | 把资源分散到整个角色名单 |
| 中期 | 补齐缺失定位、解锁关键技能组效果 | 追求一个你养不起的单一“版本答案” |
| 后期 | 优化协同和属性阈值 | 每个补丁都重建队伍 |
| 终局 / 挑战内容 | 冷门克制和专门构筑 | 以为泛用阵容能通关一切 |

一条适用于所有四个阶段的简单规则：**广度足以适应，深度足以通关。** 两三个投入良好、覆盖不同定位的角色，比六个半成品角色能带你走得更远。

## 玩家在使用 Starlathe 角色时常犯的错误

大多数角色名单问题都是决策问题，而不是知识问题。以下是反复出现的错误，以及对应的解决办法。

| 错误 | 为什么有害 | 解决办法 |
| --- | --- | --- |
| 围绕一个最爱角色组建 | 当该角色被克制时全盘崩溃 | 建立一个覆盖不同定位的三人核心 |
| 忽视控制位 | 敌人的增益和治疗无人限制 | 始终保留一个干扰选项 |
| 过度投资前期选择 | 更好的选择出现后资源被浪费 | 在明确方向前限制前期投入 |
| 盲目照抄梯度榜 | 榜单假定满投入和完美队伍 | 根据你实际的角色和装备调整榜单 |
| 跳过技能组阅读 | 错误假设导致失误 | 认真完整读一遍技能文本 |
| 忽视耐久 | 输出手还没贡献就阵亡 | 牺牲一点输出换取生存能力 |

社区报告还指出一个更微妙的问题：玩家常常在一次糟糕的补丁后就重建整支队伍，然后纳闷为什么进度停滞。补丁改变数值的频率远高于改变核心机制。如果一个角色的*功能*仍然完好，一次数值调整很少是放弃他们的理由。

## FAQ

**最先应该培养哪些最重要的 Starlathe 角色？**
先从一名可靠输出、一名辅助和一名能兼任两者之一的灵活位开始。这个核心能应对最广泛的内容，并让你的资源投入保持集中。等这三个稳定后，再为更难关卡加入一名控制和一个专职坦克。

**我需要在一支队伍里凑齐所有定位吗？**
不需要。大多数成功队伍覆盖伤害、续航和干扰，并把耐久视为全队共同承担的东西。纯定位堆叠只有在内容专门奖励它时才有效，比如一个完全无视群体控制的 Boss。

**我应该多久更换一次 Starlathe 角色？**
当你的内容变化时再换，而不是一出现补丁说明就换。如果你正从普通关卡进入挑战内容，那是调整的真正理由。如果唯一变化只是一个小数值调整，就保留你的队伍，省下资源。

**混血角色值得培养吗？**
通常只有在他们的独特效果是任何专职单位都无法提供的时候才值得。否则，两个专精角色在几乎所有场景中都胜过一个月混血角色，因为每个人都能全力完成自己的职责，而不是把力量一分为二。

**我应该去哪里查看当前角色信息？**
先从游戏自身的补丁说明和商店页面开始，再对照社区讨论获取实际语境。官方来源告诉你改了什么；玩家经验告诉你它在真实战斗中到底是什么感觉。
