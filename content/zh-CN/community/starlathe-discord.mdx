## 什么是 Starlathe Discord 社区？

Discord 是一个基于邀请制的聊天平台。它没有一条无穷无尽的信息流，而是把对话拆分到各个频道中——有些用于日常闲聊，有些专注于特定话题，还有些是语音频道。Starlathe Discord 也遵循这种结构，这正是它往往比视频下方零散的评论区更有用的原因。

来自社区的反馈显示，这个服务器兼具客服台、聚会场所和新闻站的功能。成员们在这里提问、分享发现、发布片段或截图，并组织集体活动。由于 Discord 会保留可搜索的历史记录，答案在对话结束很久之后依然可以找到——这是社交信息流很少能做到的。

如果你对这个话题完全陌生，这样一个服务器能把数周的困惑压缩进一个下午。不用靠猜，直接问就行。不用读一篇过时的攻略，而是能得到一个此刻正活跃着的人的回复。

| 区域 | 用途 | 对新人的价值 |
|---|---|---|
| 公告频道 | 更新、活动、服务器新闻 | 高——优先阅读这些 |
| 综合闲聊 | 日常交流 | 中 |
| 帮助与提问 | 排障与建议 | 高 |
| 媒体或展示 | 片段、同人作品、截图 | 中 |
| 语音频道 | 实时聊天与集体活动 | 因服务器而异 |
| 离题闲聊区 | 轻松、非主题的聊天 | 初期较低 |

## 如何加入 Starlathe Discord 服务器

加入本身很简单，但操作顺序很重要。大多数加入失败的情况，都是因为有人在未登录的状态下点击了邀请链接，或者用了已经过期的链接。按照下面的顺序操作，你几乎不会碰壁。

| 步骤 | 操作 | 为什么重要 |
|---|---|---|
| 1 | 从官方或可信来源获取邀请链接 | 避免失效链接和冒充者 |
| 2 | 点击前先登录 Discord | 未登录用户点击邀请常会失败 |
| 3 | 完成所有验证提示 | 解锁服务器的其余部分 |
| 4 | 阅读规则和公告频道 | 避免不小心被禁言 |
| 5 | 选择你的身份组 | 决定你能看到哪些频道和收到哪些提醒 |
| 6 | 简单做个自我介绍 | 更快获得老成员的热情欢迎 |

几点实用提示：

- **邀请链接会过期。** 很多服务器会刻意轮换链接。如果你的链接失效了，直接找分享给你的人要一个新的，而不是在网上到处找随机的链接。
- **绝不要付费获取访问权限。** 一个正规的 Starlathe Discord 社区不会收钱才让你进门。
- **反复核对服务器名称。** 几乎每个热门社区都存在仿冒服务器。在完成任何验证之前，先把邀请来源和官方列表对照一下。
- **手机端完全可用。** Discord 应用支持与桌面客户端相同的入门流程，只是长篇规则在大屏幕上读起来更轻松。

进去之后，先忍住立刻发帖的冲动。花十分钟阅读，就能知道什么内容该发在哪里，也能让你免于问一个当周已经被回答过三次的问题。

## 服务器内部：频道、身份组与活动

身份组是任何 Discord 服务器的引擎。它们决定你能看到什么、会收到哪些提醒，以及工作人员如何识别你。大多数 Starlathe Discord 社区都采用相似的层级结构，即便名称有所不同。

| 身份组类型 | 典型用途 | 如何获得 |
|---|---|---|
| 成员 | 对公开频道的基础访问权 | 加入时自动获得 |
| 已验证 | 确认你是真人 | 完成验证 |
| 话题身份组 | 特定兴趣的提醒 | 在身份组频道自行领取 |
| 活动身份组 | 活动和聚会的通知 | 自行领取或主动订阅 |
| 管理员／工作人员 | 执行规则与提供支持 | 由团队任命 |
| 机器人 | 自动化与实用功能 | 无法由用户分配 |

公告频道是社区日历所在之处。这些空间里分享的玩家经验往往指向同一种规律：活动会在更新、上线或预定活动前后出现高峰，然后回落到平稳的日常聊天。如果你想赶上热闹时段，就留意这些公告并相应设置你的通知。

有两个功能值得尽早学会：

- **子区（Threads）。** 与其把繁忙的频道搅乱，不如开一个子区。这样主信息流保持可读，你的问题也能更久地保持在可见位置。
- **置顶与搜索。** 提问之前，先搜索该频道。大多数反复出现的问题都已经有管理员留下的置顶答案。

## Starlathe Discord 礼仪：让社区保持健康的规则

每个服务器都会写自己的规则，但在游戏和兴趣类社区中，底层期待其实高度一致。遵守它们是让你被当作老成员而非游客对待的最快方式。

| 应该做 | 不要做 |
|---|---|
| 发帖前先阅读规则频道 | 在五个频道里刷同一个问题 |
| 把话题留在对应的频道 | 给陌生人发未经请求的私信邀请 |
| 用子区进行支线对话 | 不加预警标签就剧透 |
| 分享作品时注明创作者 | 未经允许自我推广 |
| 不确定时礼貌地询问工作人员 | 在公开场合与管理员争吵 |

有几个习惯能把优秀成员和无关紧要的成员区分开来：

1. **先搜索，再提问。** 这尊重了所有人的时间，往往也能让你更快得到答案。
2. **提供背景信息。** “它不能用”不是一个别人能回答的问题。说清楚你试了什么、发生了什么。
3. **知道答案后就回答别人。** 愿意帮助别人的人，才会得到帮助。
4. **理性分歧，不闹剧。** 辩论没问题，人身攻击不行。
5. **尊重频道用途。** 离题闲聊区存在的意义，正是让主频道能保持专注。

管理员是志愿者，不是客服人员。把他们当人而不是自动售货机，会显著改善你的体验——也会改善他们的。

## 在 Starlathe Discord 上保持安全

只要你是有意识地使用，Discord 总体上是安全的；不加思考地乱点，才会有风险。主要威胁是冒充、钓鱼链接和基于文件的诈骗——这些都不是某个服务器独有的问题。

| 风险 | 警示信号 | 该怎么做 |
|---|---|---|
| 钓鱼链接 | “免费物品，只要在这里登录” | 绝不在平台之外输入账号密码 |
| 冒充 | 工作人员私信索要你的密码 | 举报；真正的工作人员绝不会问 |
| 恶意文件 | 意料之外的 .exe 或脚本 | 不要打开；向管理员举报 |
| 账号被盗 | 你没触发过的登录提醒 | 修改密码，启用双重验证 |
| 过度分享 | 索要个人详细信息 | 隐私信息务必保密 |

为你的 Discord 账号启用双重验证，并且绝不要在多个服务间重复使用同一个密码。阅读 Discord 官方的[社区准则](https://discord.com/guidelines)，了解平台的要求，并查看 [Discord 安全中心](https://discord.com/safety)获取分步保护建议。

如果感觉哪里不对劲，请在服务器指定的频道里举报，而不是直接与对方对质。管理员能根据你看不到的行为模式采取行动，而一次快速举报也能保护下一位成员。

加入是最容易的部分。要从 Starlathe Discord 中获得价值，需要一点主动性。

最后请记住，社区是由反复出现的人建立起来的。周二打个招呼、周五回答一个问题的人，比发一段戏剧性自我介绍然后消失的人贡献更大。

## 常见问题

**加入 Starlathe Discord 是免费的吗？**
是的。Discord 服务器加入都是免费的，正规社区不会收取入场费。如果有人要求你付费换取邀请，就把它当作危险信号，直接离开。

**如果我的邀请链接失效了怎么办？**
邀请链接会过期或被轮换。向分享给你的人要一个当前有效的链接，或者查看社区的官方列表。避开随机的第三方链接聚合站，它们常常指向冒充服务器。

**我可以在手机上加入 Starlathe Discord 吗？**
当然可以。手机应用支持完整的入门流程，包括验证和身份组选择。只是长篇规则帖在桌面端读起来更轻松，所以很多成员会先在电脑上完成初始设置。

**如何在服务器内举报问题？**
使用指定的举报或支持频道；如果问题比较敏感，可以私信管理员。请附上截图和时间戳。私下举报永远好过公开争吵，把其他成员也卷进冲突之中。
