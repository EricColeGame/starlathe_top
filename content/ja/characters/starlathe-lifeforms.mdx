## スターラス生命体の何が違うのか？

スターラス生命体はこの設定の鼓動する心臓部である — 漂い、輝き、時に敵意を向ける生き物たちが、空虚な空間を生きた生態系へと変える。コーデックスのために記録するにせよ、資源を採取するにせよ、あるいは不意の遭遇をただ生き延びようとするにせよ、スターラス生命体がどう振る舞うかを理解しているかどうかが、偉大な発見とごく短い遠征との分かれ目になる。本ガイドでは主要な系統、それらを見破る兆候、そして経験豊富な探検家が新たな何かと出会ったときに頼りにするフィールド習慣を扱う。

これらの生き物を身近な野生生物と分かつのは、エネルギーとの関係である。ほとんどのスターラス生命体は、従来の意味で獲物を追いかけたりはしない。周囲の光を集め、微量の鉱物を吸収し、あるいは他の生物の副産物を餌とする。その体はそうした生活様式を映し出している — 骨と筋肉の代わりに、半透明の膜、結晶格子、ガスで満たされた袋、そして繊維の網。

| 特徴 | 典型的なスターラス生命体 | 身近な地球の類似例 |
|---|---|---|
| エネルギー源 | 周囲の光、放射線、鉱物の吸収 | 太陽光、食物連鎖 |
| 体の構造 | 格子、膜、またはガス袋 | 骨、筋肉、殻 |
| コミュニケーション | 光の脈動、振動、化学物質の軌跡 | 音声、身振り、匂い |
| 移動 | 漂い、パルスジェット、ゆっくりした滑空 | 歩行、遊泳、飛行 |
| 成長パターン | ゆっくりした付着成長、段階的な脱皮 | 連続的成長、変態 |

その生物学の違いは、彼らへの接し方のすべてを変える。光を餌とする生き物は、あなたの存在よりも先にあなたのランプに反応する。

このような空想生物学には現実世界のルーツがある。[NASAの系外惑星探査プログラム](https://science.nasa.gov/exoplanets/)は、異星の生態系に取り組むデザイナーやライターに着想を与える極限環境を追跡しており、エネルギー収支、生息地の圧力、適応といった同じ原則の多くが、スターラス生命体の成り立ちにも表れている。

## スターラス生命体の主要な系統

コミュニティの報告では、これらの生き物をいくつかの識別可能な系統に分類する傾向がある。名称は情報源によって異なるが、そのシルエットと行動は驚くほど一貫している。

| 系統 | シルエット | 出会う場所 | 気性 | 最適な対応 |
|---|---|---|---|---|
| ドリフター | 柔らかく、発光する、ゼリー状 | 開けた虚空、上層 | 好奇心旺盛、受動的 | 距離を取って観察し、照明を落とす |
| グレイザー | ずんぐりとし、板状で、動きが遅い | 鉱物に富む帯、礁に相当する場所 | 追い詰められなければ受動的 | ゆっくり動き、採食路を避ける |
| ウィーバー | 糸状、網状 | デブリ帯、構造物の間 | 反応的、縄張り意識が強い | 固定された糸には絶対に触れない |
| スウォーム | 小さく、多数、均一 | 洞窟、密集した雲 | 防御的、協調的 | 視線を切り、流れの上流へ後退する |
| 頂点型 | 大型、非対称 | 深部、古い遺構 | 捕食的、忍耐強い | 計器で追跡し、決して餌で釣らない |

### ドリフターとグレイザー：低リスクの遭遇

新米の探検家が最初に出会うスターラス生命体はたいていドリフターであり、彼らは期待を悪い方向に裏切る。漂い、輝き、無害に見える — 実際おおむね無害だ。危険なのは油断である。進路に漂い込んできたドリフターは装備を絡め取ったり、狭い通路を塞いだりしうる。

グレイザーは正反対の問題だ。遅く、重く、過小評価されやすい。採食路を妨げる何かが現れない限り、ほとんどすべてを無視する。十分な距離を取れば、相手も同じ礼儀で応えてくれる。

### スウォームとウィーバー：ほとんどのトラブルが始まる場所

スウォームは事故報告の最も一般的な原因である。個々では目立たないが、集団になると単独の探検家の不意を突く形で協調する。隊形が締まれば、あなたは値踏みされている。散開すれば、あなたは包囲されている。

ウィーバーは構造物やデブリに身を固定し、開けた空間に糸を張り巡らせる。固定された糸に触れることは、防御反応を引き起こす最も確実な方法である。

### 頂点型：火力より忍耐

頂点型は希少で、大きく、慌てることがない。プレイヤーの経験は、彼らが追いかけるのではなく待つことで狩ることを示唆しており、そのため横を通り過ぎやすく、またぶつかりやすい。ここでは目より計器が勝る。センサー範囲の端で動きを追い、説明のつかない静止は警告として扱え。

## 遭遇時の行動：兆候を読む

ほとんどのスターラス生命体は、行動する前に意図を発信している。信号は微妙だが一貫しており、それを学ぶことが生存率を上げる最速の方法だ。

| 兆候 | 通常の意味 | 推奨される対応 |
|---|---|---|
| 周期的な増光 | 採食または呼びかけ | その場に留まり、照明を落とす |
| 突然の減光 | 警戒または威嚇表示 | ゆっくり後退し、素早い動きを避ける |
| 糸が内側に丸まる | 後退 | 一時的に接近しても安全 |
| 糸が外側に広がる | 縄張りの警告 | その場から離れる |
| 隊形が締まる | 協調防御 | 視線を切り、流れの上流へ後退する |
| 隊形が散開する | パニック、または狩りの展開 | 直ちに側面を警戒する |

いくつかの習慣が、こうした読み取りをその場で格段に容易にする：

- **まず記録、触れるのは後。** 撹乱する前に記録された行動は、慌てて取ったサンプルよりはるかに価値がある。
- **相手のペースに合わせる。** 速い動きはほとんどすべての系統に捕食として読まれる。
- **常に退路を確保する。** 踏み込む前にどちらが「遠ざかる方向」かを知っておく。
- **その場所の光周期に注目する。** 活動パターンは、あなたの存在よりも照明に従うことが多い。
- **二人目の観察者を連れて行く。** 二対の目はおおよそ二倍の兆候を捉える。

## スターラスのフィールド調査の準備

準備こそ、ほとんどの調査が成功するかどうかを決める場面である。以下のチェックリストは、経験豊富な探検家によるコミュニティ報告に繰り返し現れる習慣を反映している。

| 準備段階 | なぜ重要か | よくある失敗 |
|---|---|---|
| 光周期を図に落とす | 活動は照明に従う | 活動のピークに到着する |
| 進入ベクトルを記録する | 確実な退出を保証する | 採食路へ迷い込む |
| 低出力のランプを持参する | 強い光は反応を誘発する | 光線で一帯を照らし出す |
| 採取の前に記録する | 行動データを保全する | まず対象を撹乱する |
| 二人組で調査する | 二人の観察者はより多くの兆候を捉える | 単独で行き、文脈を逃す |
| 構造上の固定点に注目する | ウィーバーの縄張りが分かる | バランスを取ろうと糸をつかむ |

パターンは単純だ。自分の行動が予測可能であるほど、生き物も予測可能になる。

## 神話、誤読、コミュニティ報告

スターラス生命体について出回っている助言の多くは、検証されたものではなく受け継がれたものだ。ここでは民間伝承とフィールドノートが分岐しがちな点を挙げる。

| よくある主張 | フィールド報告が示唆するもの |
|---|---|
| 「強い光は彼らを遠ざける」 | 光はたいていドリフターを引き寄せ、ウィーバーを興奮させる |
| 「大きいものが危険なものだ」 | 頂点型よりもスウォームのほうが多くの事故を起こす |
| 「じっとしていれば無視される」 | 静止は役立つが、薄暗い照明と組み合わせて初めて有効 |
| 「光る生き物はすべてドリフターだ」 | 複数の系統が光る。シルエットのほうが重要 |
| 「どんな相手からも逃げ切れる」 | 頂点型は追わない — 待つ |

単一の証言は一つのデータ点として扱え。コミュニティ報告は数が多いからこそ価値があるが、質は一様ではない。戦略を決める前に照合せよ。

## 自分だけのスターラス生命体をデザイン／記録する

コーデックス項目を作るにせよ、設定のための新しい生物を創作するにせよ、いくつかの核となる問いを順に考えることで、結果は一貫したものになる。

| デザイン軸 | 答えるべき問い | 例の方向性 |
|---|---|---|
| エネルギー源 | 何を消費するか？ | 周囲の光、微量の鉱物、共生 |
| 構造 | どうやって形を保つか？ | 格子、膜、ガス袋 |
| 移動方法 | どうやって動くか？ | 漂い、パルスジェット、ゆっくりした滑空 |
| 社会性 | 単独か、協調的か？ | 単独のグレイザー 対 協調するスウォーム |
| 感覚チャネル | どうやってあなたを知覚するか？ | 光への感受性、振動、化学物質の軌跡 |

この六つに答えれば、その生き物の行動はおおむね自ずと決まる。光を餌とし、格子状の体を持ち、単独で生きる生き物は、振動を感知する群体性の生き物とはまったく違う振る舞いをする — そしてその違いは、あなたに反応するより前に、その動き方に見えているはずだ。

## FAQ

**スターラス生命体とは何ですか？**
スターラス設定に固有の生き物です — エネルギー吸収を基盤とし、結晶質または膜状の体構造を持ち、音声ではなく光、振動、化学信号によってコミュニケーションをとる生物です。

**スターラス生命体は危険ですか？**
ほとんどは危険ではありません。ドリフターとグレイザーはおおむね受動的で、実際に起きる事故はたいてい採食路を妨げるか、固定されたウィーバーの糸に触れたことに起因します。大型の頂点型よりも、協調するスウォームのほうが多くのトラブルを引き起こします。

**すばやく見分けるには？**
まずシルエットを見て、次に動きのパターンを確認します。柔らかく漂う形はたいてい無害ですが、糸状のものや密集した隊形には注意が必要です。接近する前に兆候の表で確認してください。

**このような生物デザインについてもっと学ぶには？**
[NNASAの系外惑星探査プログラム](https://science.nasa.gov/exoplanets/)を含む現実の宇宙生物学の資料は、空想上の生態系を説得力あるものにするエネルギーと生息地に関する問いの、堅実な土台になります。

要するに、スターラス生命体は速さよりもはるかに忍耐に報いる。まず観察し、次に記録し、最後に接近せよ — そうすれば、より良いデータとより少ない危険な遭遇を持ち帰ることができる。
